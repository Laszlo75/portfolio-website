# Mr. Laszlo Szabo - Personal Website

This repository contains the source code for Mr. Laszlo Szabo's personal website, [lszabo.me](https://lszabo.me), built using [Quarto](https://quarto.org/).

## About

Mr. Laszlo Szabo is a Consultant Transplant Surgeon with a clinical and research focus on kidney and pancreas transplantation, organ retrieval, organ utilisation, and perioperative outcomes. Based at the Cardiff Transplant Unit, he leads initiatives aimed at improving access to transplantation, refining donor risk stratification, and optimising post-transplant care.

## Website Features

- **Home**: Personal and professional information, with social and academic profile links
- **CV**: Professional background and experience (HTML), with a downloadable PDF CV
- **Research**: Academic publications, generated from a BibTeX export of the Zotero library
- **Posts**: Blog posts and articles
- **Kidney Transplant Watch**: A weekly, AI-assisted summary of new kidney transplantation literature, with an RSS feed and email newsletter

## Technology Stack

- **Framework**: [Quarto](https://quarto.org/) - An open-source scientific and technical publishing system
- **Language**: R (`glue`, `bibtex`, `typstcv`) inside Quarto documents
- **Styling**: Custom CSS with Bootstrap (`flatly` theme)
- **PDF CV**: Typst, via the `awesomecv` Quarto extension
- **Icons**: FontAwesome icons for social media links
- **Comments**: [Giscus](https://giscus.app/), backed by the [portfolio-comments](https://github.com/Laszlo75/portfolio-comments) repo
- **Hosting**: GitHub Pages, deployed by GitHub Actions

## Project Structure

```text
├── _quarto.yml               # Quarto configuration file
├── _variables.yml            # Site variables (ORCID, email)
├── index.qmd                 # Homepage content
├── resume.qmd                # HTML CV page
├── cv.qmd                    # PDF CV (Typst; rendered separately)
├── cv.pdf                    # Rendered PDF CV
├── publications.qmd          # Publications page
├── posts.qmd                 # Blog posts listing
├── posts/                    # Blog posts, one folder per post
│   └── _metadata.yml         # Posts metadata
├── briefings.qmd             # Kidney Transplant Watch listing
├── briefings/                # Weekly briefings, one folder per issue (YYYY-MM-DD/)
├── data/                     # CSV files driving both the HTML and PDF CV
├── assets/
│   ├── my-publication-list.bib  # Publication list (Better BibTeX export)
│   ├── apa-cv.csl            # Citation style
│   └── schema-*.html         # JSON-LD structured data for pages and posts
├── images/                   # Image assets
│   ├── profile_pic.jpeg      # Profile picture
│   └── CV short 2023-04.pdf  # Short CV
├── styles.css                # Custom CSS styling
├── llms.txt                  # Site summary for AI crawlers
├── robots.txt
├── _extensions/              # Quarto extensions (fontawesome, awesomecv)
└── .github/                  # Publish workflow and newsletter script
```

`_site/` (the rendered website) is generated by `quarto render` and is not committed.

## Local Development

### Prerequisites

- [R](https://www.r-project.org/) (version 4.0 or higher)
- [RStudio](https://www.rstudio.com/) or Positron (recommended)
- [Quarto](https://quarto.org/docs/get-started/) CLI

### Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/Laszlo75/portfolio-website.git
   cd portfolio-website
   ```

2. Install the required R packages:

   ```r
   install.packages(c("knitr", "rmarkdown", "glue", "bibtex", "typstcv"))
   ```

3. Preview the website locally:

   ```bash
   quarto preview
   ```

   or in RStudio, use the "Render" button

### Building the Site

To build the website locally:

```bash
quarto render
```

The generated website will be in the `_site/` directory. The PDF CV is excluded from the site build; render it separately with `quarto render cv.qmd`.

## Deployment

Every push to `main` triggers `.github/workflows/publish.yml`, which renders the site and deploys it to GitHub Pages at [lszabo.me](https://lszabo.me). If a push adds a new `briefings/<date>/index.qmd`, the workflow also schedules that issue as an email to the Kidney Transplant Watch subscribers via Buttondown.

## Customization

### Adding New Content

- **Blog Posts**: Add a new folder in `posts/` with an `index.qmd`
- **Briefings**: Add a new `briefings/YYYY-MM-DD/index.qmd`
- **Pages**: Create new `.qmd` files in the root directory and update `_quarto.yml`
- **Publications**: Replace `assets/my-publication-list.bib` with a fresh Better BibTeX export
- **CV**: Edit the CSV files in `data/`; both `resume.qmd` and `cv.qmd` read from them

### Styling

- Custom styles can be added to `styles.css`
- Site-wide variables can be modified in `_variables.yml`
- Quarto configuration can be adjusted in `_quarto.yml`
